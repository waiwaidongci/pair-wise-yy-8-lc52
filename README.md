# 古法纸浆发酵记录

运行：

```bash
npm start
```

访问`http://localhost:3039`。数据保存在`data/paper-pulp-fermentation.json`。

## 业务入口

- `/` 发酵批次：建档投料入口。浸泡缸须持有效复检放行单，未放行时按钮禁用并说明未过项，原批次内容照旧保留。
- `/inspections` 复检记录：空缸复检放行单，登记冲洗遍数、残水酸碱度（pH）、霉点；三项全部通过才放行。
- `/vats` 缸位放行：各缸位放行状态与三项明细。放行后超过半天（12 小时）未投料建档，放行自动失效，须重新复检；建档后放行单即被占用。
